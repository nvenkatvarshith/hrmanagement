**KRIS – Community Engagement Platform 🤝**
KRIS is a high-fidelity frontend replication of a professional community engagement platform. Built with a focus on clean architecture and modular design, this project demonstrates a pixel-perfect transition from Figma design to a functional Next.js application.

🔗 View Figma Design Reference - https://www.figma.com/design/kxTc7Cifym2GsTffdEeOnk/KRIS--Community-?node-id=0-1&p=f&t=WCYfMPfm8RvcO3hO-0

**🚀 Overview**
The KRIS platform is designed to provide an intuitive interface for community management and member engagement. This repository focuses on implementing a structured navigation flow using Next.js Route Groups and maintaining design consistency across Admin, Auth, and User modules.

**🛠 Tech Stack**
Framework: Next.js 14/15 (App Router)
Language: TypeScript
Styling: Tailwind CSS
Icons: Lucide React
Design: Figma

**✨ Key Features**
Modular Route Groups: Organized application logic using (admin), (auth), and (user) groups for clean URL structures and layout separation.
Design-to-Code Precision: Faithful reconstruction of the KRIS Figma file, including typography, spacing, and brand-specific color palettes.
Unified UI Components: A centralized Components directory within the app folder for reusable elements like Navbars, Sidebars, and specialized Buttons.
Responsive Architecture: Fully optimized for different screen sizes, ensuring a seamless experience from mobile to desktop.
Type Safety: Developed with TypeScript to ensure robust code and catch potential errors during development.

**🎨 Figma Implementation**
This project was built to match the following design specifications:
Figma File: KRIS Community Engagement Design - https://www.figma.com/design/kxTc7Cifym2GsTffdEeOnk/KRIS--Community-?node-id=0-1&p=f&t=WCYfMPfm8RvcO3hO-0
The focus was on replicating the visual hierarchy, interactive states, and layout flows.

**📂 Project Structure**
As seen in the source code, the project follows a modern Next.js App Router pattern:

Plaintext
app/
 ├── (admin)/        # Admin-specific routes and layouts
 ├── (auth)/         # Authentication flow (Login/Signup)
 ├── (user)/         # User-facing community features
 ├── Components/     # Modular and reusable UI components
 ├── globals.css     # Global styles and Tailwind directives
 ├── layout.tsx      # Root application layout
 └── page.tsx        # Homepage / Landing entry point
public/              # Static assets (images, fonts, icons)

**⚙️ Installation & Setup**
Clone the repository:
Bash
git clone https://github.com/nvenkatvarshith/hrmanagement.git

Navigate to the project folder:
Bash
cd hrmanagement

Install dependencies:
Bash
npm install

Run the development server:
Bash
npm run dev
Open http://localhost:3000 to view the project.
